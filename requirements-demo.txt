# opencv-python-headless, NOT opencv-python. FALCONPRD is a server; the non
# headless wheel links libGL.so.1 and friends, which are usually absent on a
# headless host and fail at `import cv2` with an OSError, not a pip error.
# Both wheels provide the same `cv2` module, so quality_check.py cannot tell.

# ── UI ───────────────────────────────────────────────────────────────────────
# Held below 6 deliberately. gradio 6 moved css=/head= from the Blocks
# constructor to launch(); vlm_test_client_v2._theme_kwargs() handles both, but
# a single 4/5-series pin is one less thing to be wrong on stage. gr.skip(),
# which the batch UI's _emit() depends on, exists from 4.x onward.
gradio>=4.44,<6

# ── Stage 1 segmentation ─────────────────────────────────────────────────────
# rembg pulls a large transitive set (scipy, scikit-image, pymatting, pooch)
